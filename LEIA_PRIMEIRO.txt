ALTERAÇÕES DESTA VERSÃO
- PORTARIA: ao ler o QR, o sistema NÃO libera a entrada imediatamente.
- PORTARIA: primeiro aparecem nome, evento, lote/setor e status.
- PORTARIA: a entrada só é registrada ao tocar em “CONFIRMAR ENTRADA”.
- ADMIN: “LIMPAR INGRESSOS” apaga definitivamente os ingressos/testes antigos e deixa a lista zerada.

PASSO OBRIGATÓRIO UMA VEZ
1. Abra Supabase > SQL Editor > New query.
2. Cole o conteúdo de SUPABASE_V9_PORTARIA_LIMPEZA.sql.
3. Clique Run. Deve aparecer Success.
4. Depois envie os arquivos HTML/JS deste pacote para a raiz do GitHub, substituindo os atuais.

TESTE DA PORTARIA
1. Abra Portaria e faça login.
2. Toque “LER QR CODE”.
3. Leia um ingresso pago.
4. Deve aparecer o NOME e os dados do ingresso.
5. Só então toque “CONFIRMAR ENTRADA”.
6. Uma segunda leitura deve aparecer como “JÁ ENTROU”.
