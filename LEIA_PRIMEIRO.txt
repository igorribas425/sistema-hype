HYPE GITHUB PIX AUTO V12
========================

O que mudou nesta versão
------------------------
1. Cada evento pode ter suas próprias categorias/setores: Pista, VIP,
   Camarote, Backstage, Open Bar ou qualquer nome que você quiser.
2. Cada categoria tem PREÇO FEMININO e PREÇO MASCULINO separados.
3. O Admin consegue criar categorias novas e editar os dois valores depois.
4. Quantidade, início da venda e expiração continuam configuráveis por categoria.
5. O cliente escolhe o gênero e o sistema mostra automaticamente o preço correto.
6. O ticket é criado no Supabase já com o valor correto para aquele gênero.
7. O PIX continua usando a integração Asaas já instalada; a V12 grava no ticket o preço escolhido.
8. Ingressos antigos não têm o valor alterado.
9. Tudo da V11 continua: pagamento automático, Gmail, QR do ingresso e Portaria.

PASSO 1 - SUPABASE (FAZER PRIMEIRO)
-----------------------------------
Abra Supabase > SQL Editor > New query.
Cole TODO o arquivo:
SUPABASE_V12_CATEGORIAS_PRECOS_GENERO.sql

Clique em Run UMA VEZ.
O esperado é: Success / No rows returned.

Esse SQL NÃO apaga ingressos, eventos nem usuários.
Ele apenas adiciona os dois preços e cria as funções V12.

PASSO 2 - GITHUB
----------------
Depois do SQL funcionar, substitua na raiz do repositório os arquivos:
- index.html
- cliente.html
- admin.html
- evento.html
- portaria.html
- app.js
- supabase-config.js
- logo-hype.png

Você também pode enviar a pasta inteira do ZIP para substituir a versão anterior,
mas NÃO publique arquivos de backend/secrets em repositório público.

NÃO PRECISA ALTERAR O WEBHOOK DO ASAAS
---------------------------------------
O webhook da V11 continua igual.
Não troque HYPE_APPS_SCRIPT_URL, HYPE_WEBHOOK_SECRET, ASAAS_WEBHOOK_TOKEN,
SUPABASE_SERVICE_ROLE_KEY nem ASAAS_API_KEY.

COMO USAR NO ADMIN
------------------
1. Crie ou selecione um evento.
2. Clique em CATEGORIAS & PREÇOS.
3. Informe o nome do lote e a categoria (Pista, VIP, Camarote etc.).
4. Informe Preço Feminino e Preço Masculino.
5. Informe quantidade e, se quiser, início/expiração.
6. Clique em CRIAR CATEGORIA / LOTE.
7. Para mudar valores depois, altere os campos e clique SALVAR CATEGORIA.

TESTE RECOMENDADO
-----------------
Crie uma categoria de teste com valores diferentes:
- Feminino: R$ 10,00
- Masculino: R$ 20,00

No site do cliente, troque o gênero e confira se o preço muda.
Depois gere um PIX novo e confira se o banco mostra o mesmo valor escolhido.
