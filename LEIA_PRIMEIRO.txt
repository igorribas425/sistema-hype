HYPE GITHUB PIX AUTO V11
========================

O que mudou nesta versão
------------------------
1. PIX continua sendo gerado pelo Asaas.
2. Quando o banco recebe "Pago", a página do cliente mostra:
   PAGAMENTO CONFIRMADO -> ACESSAR MEU INGRESSO.
3. O ingresso oficial continua no próprio site, com QR Code para a Portaria.
4. O Gmail é enviado automaticamente pelo webhook do Asaas, sem depender
   do botão "Confirmar" do Admin.
5. A tela informa se o e-mail já foi enviado ou se ainda está processando.
6. As correções da V10 de Portaria e limpeza foram mantidas.

ARQUIVOS DO GITHUB
------------------
Suba para a raiz do repositório:
- index.html
- cliente.html
- admin.html
- evento.html
- portaria.html
- app.js
- supabase-config.js
- logo-hype.png

NÃO é necessário subir para o GitHub:
- SUPABASE_V11_EMAIL_AUTOMATICO.sql
- ASAAS_WEBHOOK_EMAIL_AUTOMATICO_V11.ts
- pasta BACKEND_SUPABASE_V11

SUPABASE - SQL (uma vez)
------------------------
Abra Supabase > SQL Editor > New query.
Cole SUPABASE_V11_EMAIL_AUTOMATICO.sql e clique Run UMA VEZ.
Este SQL não apaga ingressos/eventos/lotes.

SUPABASE - EDGE FUNCTION ASAAS
------------------------------
Abra a Edge Function que recebe o webhook do Asaas (asaas-webhook).
Substitua o código pelo arquivo:
ASAAS_WEBHOOK_EMAIL_AUTOMATICO_V11.ts

A função precisa estar com Verify JWT DESATIVADO, porque o Asaas chama
o webhook diretamente e não envia JWT do Supabase.

Secrets necessários no Supabase:
- HYPE_APPS_SCRIPT_URL
- HYPE_WEBHOOK_SECRET
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY

Opcional, para validar o webhook:
- ASAAS_WEBHOOK_TOKEN

IMPORTANTE
----------
Não coloque SERVICE_ROLE, token do Asaas ou HYPE_WEBHOOK_SECRET no GitHub.

Fluxo final esperado
--------------------
Cliente gera PIX
-> paga
-> Asaas confirma
-> webhook muda ticket para Pago
-> webhook chama Gmail/Apps Script
-> site mostra PAGAMENTO CONFIRMADO
-> botão ACESSAR MEU INGRESSO
-> QR Code do ingresso
-> e-mail enviado automaticamente
-> Portaria lê QR, mostra os dados e pede confirmação de entrada.
