HYPE V16.10 — LINK DE PROMOTER REVOGÁVEL

CORREÇÃO
- O link do promoter não é mais aceito apenas porque existe na URL.
- O site valida o código no Supabase.
- Se o Admin EXCLUIR ou DESATIVAR o promoter:
  * o link antigo aparece como inválido/revogado;
  * o campo promoter fica vazio;
  * a compra por aquele link é bloqueada;
  * nenhuma venda nova pode ser atribuída ao promoter removido.
- Vendas antigas permanecem no histórico.

PASSOS
1. Rode SUPABASE_V16_10_PROMOTER_LINK_REVOGADO.sql no SQL Editor do Supabase.
2. Suba os arquivos do ZIP no GitHub, substituindo os atuais.
